# v1.9 首次使用引导与会话聚焦设计（前端子设计）

> 本文只覆盖 v1.9 的前端引导与会话聚焦。续跑核心协调器的后端重构见
> [`v1.9_resume_coordinator_design.md`](./v1.9_resume_coordinator_design.md)。

## 背景

AgentPulse 的核心链路已经完整，但首次打开时总览只显示六个零值指标、一个空会话框和空日志。用户不知道应用是否需要先启动、应该去哪里启动 Agent，也不知道“非侵入守护”意味着什么。会话变多后，当前列表只能按注意力排序，无法快速缩小到“正在等我”或某个项目。

## 目标与验收标准

1. **首次空状态可行动**：没有会话时，总览显示三步引导，并可直接开始守护、立即扫描、前往设置。
2. **把产品边界说清楚**：引导明确说明 AgentPulse 不启动/接管 Agent，定位不到终端时不会盲目输入。
3. **多会话可聚焦**：会话列表支持文本搜索及“全部 / 等我 / 卡住 / 活跃”筛选，结果仍沿用注意力优先排序。
4. **空结果可恢复**：筛选无结果时提供清除入口，不让用户误以为会话消失。
5. **架构收口**：`App.tsx` 只负责应用壳和导航；总览编排下沉到 `DashboardPanel`；搜索、筛选、排序规则放入纯函数模块并有单测。
6. **中英双语与可访问性**：所有新增文案进入 i18n；输入框有可读名称；筛选使用现有 Radix 单选段控件；状态不只靠颜色表达。

## 三个视角

### 前端

- 新增 `DashboardPanel`、`OnboardingPanel`。
- `SessionList` 增加搜索框、段控件和结果计数。
- 新增 `lib/sessions.ts`，UI 不内嵌筛选策略。

### 后端

本轮不新增 IPC。引导只使用现有 `start_monitoring`、`scan_now` 和配置页入口；会话过滤只作用于已从 Rust 返回的内存快照，不改变判定来源。

### 安全

- 不把命令字符串自动执行，只以 `<code>` 形式展示。
- 不读取或展示会话正文；搜索仅在现有会话元数据上运行。
- 不因引导放宽 `auto_follow_latest`，仍保持“定位不到就不敲”的默认安全边界。
- 不持久化搜索关键词，避免把项目路径或终端信息写入额外存储。

## 非目标

- 不做 Agent 启动器或任务编排。
- 不在无会话时伪造权限健康结论；精确投递演练仍需基于真实会话。
- 本前端子设计不通过 UI 重算或覆盖 Rust 检测、动作闸门与续跑策略；后端协调器由独立规格定义。
